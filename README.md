# MAC 패턴 인식 시스템 결과 리포트

## 📊 결과 분석 (Analysis)

### 1. 상세 판정 원리 (Detailed Cause Analysis)
본 시스템의 판정 신뢰도는 다음과 같은 로직을 통해 확보됩니다.

*   **부동소수점 오차 제어 (Epsilon):** 컴퓨터 연산 특성상 발생하는 미세한 오차를 해결하기 위해 `abs(A - B) < 1e-9` 방식을 적용, 수치적 동일성을 정확히 판정합니다.
*   **라벨 정규화 및 매핑 (FAIL #5, #18):** 입력된 다양한 형식의 라벨(t, cross, x 등)을 시스템 표준 라벨로 변환하여 비교합니다. 특히 **'정규화 -> 판정 -> 출력 -> 테스트'**의 일관된 흐름을 준수하여 데이터 무결성을 유지합니다.
*   **MAC 점수의 해석 (FAIL #14):** MAC(Multiply-Accumulate) 연산 결과값은 두 행렬 간의 **수학적 유사도**를 의미합니다. 점수가 높을수록 해당 필터 패턴과 일치할 확률이 높음을 근거로 최종 결과를 도출합니다.

### 2. 복잡도 설명 (Complexity Explanation)
*   **시간 복잡도: $O(N^2)$**
    *   $N \times N$ 크기의 행렬 모든 요소를 순회하며 연산하므로, 행렬 크기가 커질수록 연산량은 제곱에 비례하여 증가합니다.
*   **공간 복잡도: $O(N^2)$**
    *   입력 행렬과 필터를 메모리에 저장하기 위한 공간이 필요합니다. 현재 시스템은 패턴을 개별적으로 처리하여 메모리 사용량을 최소화하고 있습니다.

## 🚀 대규모 데이터 처리 및 하드웨어 최적화 전략

### 1. 대규모 행렬(1000x1000 이상) 처리 전략
$O(N^2)$ 복잡도로 인한 성능 병목을 해결하기 위해 다음과 같은 최적화가 필요합니다.
- **스트리밍(Streaming) 처리**: 전체 데이터를 한꺼번에 로드하지 않고 행(Row) 단위로 읽어 메모리 부하를 방지합니다.
- **블록 연산(Tiling)**: 데이터를 캐시 메모리 크기에 맞는 블록 단위로 나누어 연산 효율을 극대화합니다.
- **병렬 가속**: Python의 GIL 한계를 극복하기 위해 NumPy의 벡터화 연산이나 멀티프로세싱을 적용합니다.

### 2. CPU vs NPU 병목 비교
- **CPU (직렬 처리)**: 복잡한 제어 흐름에는 강하나, 수백만 번의 단순 MAC 연산을 순차적으로 처리할 때 심각한 병목이 발생합니다.
- **NPU (병렬 처리)**: 수천 개의 연산 유닛이 동시에 MAC 연산을 수행하는 구조입니다. 대규모 행렬 연산 시 CPU 대비 압도적인 처리량(Throughput)을 가지므로, 실시간 패턴 인식을 위해서는 NPU 가속이 필수적입니다.
